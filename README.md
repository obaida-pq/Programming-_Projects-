# Programming-_Projects
Console Bank Simulator

A simple console-based bank simulator built with C++. This project was created as a beginner programming project to practice object-oriented programming (OOP), classes, vectors, static members, loops, and conditional statements.

Features

- Create an Account: Create a new account using a unique name.
- Login: Access an existing account by entering its name.
- Deposit: Add money to the account balance.
- Withdraw: Withdraw money if the amount is valid and the balance is sufficient.
- Transaction History: View recorded transactions.
- Account Information: Display the account name, total number of transactions, and current balance.
- Input Validation: Prevent duplicate account names and reject invalid deposit and withdrawal amounts.
- Logout: Leave the current account and return to the main menu.
- Exit: Close the program.

Technologies Used

- C++
- Standard Template Library (STL)
- "vector"
- Object-Oriented Programming (OOP)

How to Run

1. Clone or download this repository.
2. Open the source file in a C++ IDE, such as Code::Blocks.
3. Compile the program using a compiler that supports C++17 or later.
4. Run the executable.
5. Follow the instructions displayed in the console.

Concepts Practiced

This project helped me practice:

- Classes and objects
- Constructors
- Public and private members
- Static data members and static member functions
- Vectors and storing transaction history
- Functions and conditional statements
- Loops and input handling
- Basic account and transaction logic

Limitations

- This is an educational project, not a real banking application.
- Account data is stored in memory and is lost when the program closes.
- Accounts are identified by names rather than secure credentials.
- The program does not use a database or persistent storage.
